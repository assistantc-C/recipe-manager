# iOS ショートカットで「共有 → レシピ管理に追加」を実現する

> **対象**：iPhone / iPad ユーザー
> **所要時間**：5 分
> **必要なもの**：Apple の「ショートカット」アプリ（iOS 標準・無料）

## なぜこの手順が必要か

Android / デスクトップ Chrome では、PWA をインストールすると **Web Share Target API** によって共有メニューに「レシピ管理アプリ」が自動で出てきます。

しかし **iOS Safari は Web Share Target API に未対応**（2026 年 5 月時点）。
そのため iOS では同等の機能を「ショートカット」アプリで自作する必要があります。

良い知らせ：レシピ管理アプリ側は `?shared_url=` という URL パラメータを受け取って自動でレシピ追加モーダルを開く仕組みを既に持っているので、ショートカットからそれを叩くだけで完結します。

---

## 仕組み

```
[Safari で YouTube / レシピページ]
   ↓ 共有ボタン
[共有シートに「レシピ管理に追加」]   ← 自作ショートカット
   ↓ タップ
[https://assistantc-c.github.io/recipe-manager/recipe-manager.html?shared_url=<URL>]
   ↓ 自動的に
[追加モーダルが開く + URL が入力済み + AI でタイトル取得]
```

---

## 作成手順

### 1. ショートカットアプリを開く

iPhone のホーム画面から **ショートカット**アプリを開く（プリインストール）。

### 2. 新規ショートカットを作成

- 右上の **「+」** ボタンをタップ
- 「**新規ショートカット**」が開く

### 3. 入力を共有シートから受け取る設定

- 上部の **「i」インフォメーションボタン**（または「ショートカットの詳細」）をタップ
- **「共有シートに表示」**をオン
- **「共有シートのタイプ」**で：
  - ✅ **URL** をオン
  - その他はオフでOK
- 完了

### 4. アクションを追加（2 つだけ）

#### アクション 1：URL のエンコード

- 検索バーに **「URLエンコード」**と入力
- **「テキストをURLエンコード」** アクションを追加
- アクションのフィールドをタップ → **「ショートカットの入力」** を選択
  - 共有シートから渡された URL がここに入る

#### アクション 2：URL を開く

- 検索バーに **「URLを開く」**と入力
- **「URLを開く」** アクションを追加
- URL フィールドに以下を入力：
  ```
  https://assistantc-c.github.io/recipe-manager/recipe-manager.html?shared_url=
  ```
  - 続けて、**マジック変数**として **「URLエンコード済みテキスト」** を末尾に挿入
  - （マジック変数は青いバッジで表示される）

完成形のイメージ：

```
[テキストをURLエンコード]
  ┃ 入力: ショートカットの入力
  ┃ 出力: URLエンコード済みテキスト
  ▼
[URLを開く]
  ┃ URL: https://assistantc-c.github.io/recipe-manager/recipe-manager.html?shared_url=【URLエンコード済みテキスト】
```

### 5. 名前とアイコンを設定

- 上部のショートカット名を **「レシピ管理に追加」** に変更
- 左側の四角アイコンをタップして好きな色・絵文字に（🍳 🥗 など）

### 6. 保存

- 右上の **完了** をタップ

---

## 使い方

### YouTube の動画を取り込む例

1. Safari または YouTube アプリで動画を開く
2. **共有ボタン** をタップ
3. 共有シートを下にスクロール → **「レシピ管理に追加」** をタップ
4. レシピ管理アプリが Safari で開く
5. 自動的に「レシピを追加」モーダルが開いて、URL 欄が入力済みになる
6. AI 解析が走ってタイトルが自動取得される
7. 必要に応じて材料・手順を編集して保存

### レシピサイトを取り込む例

1. Safari でレシピページを開く
2. **共有ボタン** → **「レシピ管理に追加」**
3. 同上のフローで取り込み

## トラブルシューティング

### 共有シートに「レシピ管理に追加」が出ない

- ショートカットアプリで作成したショートカットの **「i」** から「**共有シートに表示**」がオンか確認
- 「共有シートのタイプ」で **URL** がオンか確認
- iOS を再起動

### タップしても何も起こらない

- ショートカットアプリで該当ショートカットを直接実行してみて、エラーが出ていないか確認
- URL フィールドの末尾に **マジック変数（青バッジ）** がちゃんと挿入されているか確認（手入力では機能しない）

### モーダルは開くけど URL が入っていない

- マジック変数が **「URLエンコード済みテキスト」** ではなく別のものになっていないか確認
- 「テキストをURLエンコード」アクションの入力が **「ショートカットの入力」** になっているか確認

---

## 補足：Android / PC ではこの設定は不要

このショートカットは **iOS 専用の代替手段**です。Android / PC Chrome では PWA をインストールするだけで、ネイティブの共有メニューに「レシピ管理アプリ」が自動的に登場します。
